**** battery conservation

Battery Conservation Mode on IdeaPad laptops
(limits charging to 55-60% of its capacity to improve battery life)

#1  make sure the ideapad_laptop kernel module is loaded
#+BEGIN_EXAMPLE
    $ lsmod | grep ideapad_laptop
#+END_EXAMPLE

#2  If it is, run as root to enable Battery Conservation Mode:
#+BEGIN_EXAMPLE
   # echo 1 >/sys/bus/platform/drivers/ideapad_acpi/VPC2004:00/conservation_mode
#+END_EXAMPLE

0 = disable feature
1 = enable feature
