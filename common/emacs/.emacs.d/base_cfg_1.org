|-----------------+-------------------------------|
| Identical pair  | Why                           |
|-----------------+-------------------------------|
| TAB / C-i       | Both are byte 9               |
| RET / C-m       | Both are byte 13              |
| ESC / M- prefix | ESC is byte 27, same          |
|                 | as Meta prefix                |
| DEL / C-h       | Both byte 8 on some           |
|                 | terminals (backspace vs help) |
| SPC / C-@       | Not identical but             |

|-----------------+-------------------------------|
